# 《金融危机本质》动效表（Remotion 技术规格）

> 目标：科普高级感。用代码精确动效把密集数字/图表做出"数据可视化大片"质感。
> 技术栈：Remotion 4.0.380 + React 19（工程已搭好，见 remotion-app/）
> 复用：黄仁勋片子的 spring 入场 / interpolate 渐变 / 径向渐变呼吸背景写法。

## 核心动效组件库（可复用，按数据类型封装）

### 1. NumberTicker 数字滚动计数器
- 用途：337万亿/39万亿/42倍/5600亿等所有大数字
- 实现：`interpolate(frame, [start,end], [0, 目标值])` + `Math.round` + 千分位格式化；落定时 spring 弹一下放大再回弹
- 高级感细节：滚动时数字模糊（blur），落定瞬间清晰 + 高光扫过

### 2. BarRace 对比柱
- 用途：利息1.23万亿 vs 国防预算 / 5600亿投入 vs 350亿营收
- 实现：两根柱 `spring` 高度生长，落差大时矮柱闪红；柱顶挂 NumberTicker

### 3. RingProgress 环形进度
- 用途：债务占GDP 127% 冲破 60%安全线 / 通胀3.4% vs 目标2%
- 实现：SVG circle `strokeDashoffset` 用 interpolate 生长；超过红线阈值时整环转红+脉冲

### 4. DualBarSwap 双柱此消彼长
- 用途：黄金27% 反超 美债22%
- 实现：两柱同时反向生长，交叉瞬间金柱高光+登顶标注"30年首次"

### 5. FlowCycle 资金循环箭头
- 用途：英伟达→OpenAI→甲骨文→英伟达 闭环
- 实现：三节点定位三角，箭头路径 `strokeDashoffset` draw-in 依次点亮，钱币 icon 沿路径平移；闭环完成后中心浮现"左手倒右手"

### 6. Timeline 时间轴
- 用途：1987→2000→2008 罗杰斯押中 / 危机预言时间点
- 实现：横线 draw-in，节点圆点 stagger 逐个 spring 弹出+爆闪，节点下挂年份+事件标签

### 7. CardStagger 信息卡逐条
- 用途：人物 credentials / 四条建议
- 实现：卡片 `translateY+opacity` 错峰（delay = index×6帧）滑入，序号大字先行

### 8. TitleReveal 标题逐字
- 用途：开场标题 / 结尾金句
- 实现：按字 split，每字 delay×3帧 spring 浮现；金句配下划线 draw-in

### 9. BubbleBurst 泡沫膨胀破裂
- 用途：AI泡沫 / 互联网泡沫
- 实现：圆 scale 持续放大到阈值，破裂帧切换为粒子四散（多个小圆 random 抛射 + opacity 衰减）

### 10. ChapterCard 章节卡
- 用途：原因一/二/三 分段
- 实现：超大数字"01/02/03"从侧滑入，主色块翻转，标题跟随；停 0.5s 后整体上移让位正文

## 实施顺序建议

1. 先做 `components/` 通用库（10 个组件，最大复用）
2. 再按幕组装 Composition（每幕一个 Sequence）
3. 数字/图表数据抽成 `data.ts` 常量，改数不改码
4. 配音先用 noiz-tts 生成，拿到每句时长 → 反推每镜头精确帧数
5. 实拍质感场景（论坛/演讲台/金条）走小云雀生成，下载进 assets_xyq/ 作背景层
