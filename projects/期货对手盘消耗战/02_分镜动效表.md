# 《对手盘消耗战》分镜+动效表（竖屏 1080×1920 / 30fps / 175.6秒 / 5268帧）

> 配音：帝皇菠萝堡 2'56"。风格：黑金极简 + 概念可视化。
> 每镜按 remotion-motion-craft 准则设计：先抓概念→选物理隐喻→定缓动/物理/镜头。**拒绝套模板**。

## 视觉系统
- 底：纯黑 #08090C + 暗金噪点 + 极淡透视网格 + 暗角
- 多头=暖红 #FF3B3B，空头=青绿 #00E5C8，钱/价格=金 #FFC83D
- 字：思源黑体 Heavy，大字号，霓虹外发光
- 缓动默认 `Easing.bezier(0.16,1,0.3,1)`；强调过冲 `(0.34,1.56,0.64,1)`；金句 `(0.45,0,0.55,1)`
- 全程 stagger 错峰，关键元素带物理（过冲/加速/冲击波/张力）
